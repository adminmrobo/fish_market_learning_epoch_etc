## 슬라이드 4 — 앞 단계와 이번 단계의 연결

- 라벨: `SECTION 0 · 흐름`
- 제목: **상자 밖에서 손잡이를 돌리다가, 이번엔 상자를 연다**
- 왼쪽 열 "앞 단계 (KNN·SVC 실습)":
  - Phase #1: 데이터와 알고리즘(KNN, SVC)을 정하고 기본값으로 학습
  - Phase #2: k, kernel, C를 바꿔 가며 가장 좋은 값 찾기
  - Phase #3: 변수를 바꾸거나 늘려서 비교
- 오른쪽 열 "이번 단계":
  - ① 상자 열기: `fit()` 안에서 가중치가 고쳐지는 과정(경사하강법)을 직접 본다
  - ② 손잡이 추가: 학습률·배치·에포크 = **가중치를 어떻게 찾아가는가**를 정하는 값
  - ③ 상자 여러 개: 하나를 고르지 말고 합치면? (앙상블)
- 하단: Phase #1에서 가중치가 안 보였던 이유 — SVC는 `fit()` 안에서 알아서 계산했고, KNN은 애초에 가중치가 없다(데이터를 저장했다가 비교만 한다).
- [노트] Phase #3을 하면 Phase #2를 다시 해야 한다. 변수가 바뀌면 최적의 k도 바뀐다(슬라이드 27에서 확인).

## 슬라이드 8 — 0층위: 데이터 분할과 random_state

- 라벨: `SECTION 1 · 0층위 · 분할`
- 제목: **무엇으로 배우고, 무엇으로 판정할까**
- 3단 그림 (상자 세 개):
  - **훈련 118마리** → ① 가중치 학습
  - **검증 = 훈련 118마리 안에서 5겹 교차검증** → ②③ 설정 고르기
  - **시험 40마리** → 마지막에 한 번만 성적 보고
- 코드:

```python
from sklearn.model_selection import train_test_split, StratifiedKFold
train, test = train_test_split(df, test_size=0.25,
                               stratify=df['Species'],   # 어종 비율 유지
                               random_state=42)          # 재현성
cv = StratifiedKFold(5, shuffle=True, random_state=42)    # 검증용 5겹
```

- 오른쪽 설명:
  - **stratify**: Whitefish가 6마리뿐이라, 비율을 지정하지 않으면 시험에 한 마리도 안 들어갈 수 있다.
  - **random_state**: 같은 코드를 다시 돌리면 같은 결과가 나오게 고정하는 장치. **튜닝 대상이 아니다.** 값을 바꿔 가며 가장 좋은 걸 고르면 "운 좋은 분할"을 고른 것이다.
  - **StandardScaler**: KNN·SVC는 거리에 민감하므로 평균 0, 표준편차 1로 맞춘다. 훈련 데이터로만 맞추고 시험에는 적용만 한다.
- [노트] 앞 장 농어 버전은 훈련/시험 둘로만 나눴다. 하이퍼파라미터를 시험 점수로 고르면 그 점수가 부풀려지므로 이번엔 교차검증을 따로 둔다.

- 제목: **계수를 바꾸면 틀린 정도가 바뀐다 — 그 관계가 손실 함수**
- 본문:
  - 모델의 계수(가중치)를 바꾸면 예측이 달라지고, 틀린 정도도 달라진다.
  - 이 관계를 **비용 = f(계수)** 로 놓은 것이 손실 함수다.
  - 학습은 이 비용이 가장 작아지는 계수를 찾는 일이다.
- 2단 비교 상자:
  - **손실**: 학습 중에 줄이는 대상. 매끄럽다. 계수를 조금 바꾸면 값도 조금 변한다 → 기울기를 계산할 수 있다.
  - **정확도**: 학습 후에 보는 성적표. 계단 모양이다. 계수를 조금 바꿔도 맞힌 개수는 대개 그대로라 기울기가 0 → 방향을 알려주지 못한다.
- 경제학 대응 띠: 손실 함수 = 비용함수, 계수 = 선택변수, 크로스 엔트로피 최소화 = 로그우도 최대화(MLE)
- [그림] 왼쪽: 매끄러운 그릇 모양 곡선(손실), 오른쪽: 계단 모양 선(정확도)

## 슬라이드 14 — 손실 함수의 종류와 MSE 계산

- 라벨: `SECTION 3 · MSE`
- 제목: **MSE — 크게 틀린 것을 아주 크게 혼낸다**
- 표:

| 손실 함수 | 문제 유형 | 계산 |
|---|---|---|
| 평균 제곱 오차(MSE) | 회귀 | (실제값 − 예측값)²의 평균 |
| 이진 크로스 엔트로피 | 이진 분류 | −log(정답 확률)의 평균 |
| 범주형 크로스 엔트로피 | 다중 분류 (이번 장) | −log(정답 확률)의 평균 |

- 계산 예 코드 상자:

```
실제 무게:  [100, 200, 300]
예측 무게:  [110, 190, 330]
오차:       [ 10, -10,  30]
제곱:       [100, 100, 900]
MSE = (100 + 100 + 900) / 3 = 366.7     √MSE ≈ 19.1g
```

- 오른쪽 메모: 10g 틀리면 100, 30g 틀리면 900. 단위가 g²이라 직관적이지 않으므로 √MSE를 함께 본다.

## 슬라이드 16 — 정확도와 손실은 같은 모델을 다르게 본다

- 라벨: `SECTION 3 · Case`
- 제목: **정확도가 같아도 손실은 다르다**
- 표:

| 모델 | 시험 정확도 | 손실 (크로스 엔트로피) |
|---|---|---|
| 로지스틱 회귀 | 82.5% | 0.590 |
| SVC (rbf) | 82.5% | 0.473 |
| KNN (k=5) | 77.5% | **2.129** |

- 해석:
  - 로지스틱과 SVC는 정확도가 같지만, SVC가 정답에 더 높은 확률을 줘서 손실이 작다.
  - KNN 손실이 유독 큰 이유: KNN의 확률은 "이웃 5마리 중 몇 마리"라서 0%, 20%처럼 끊어진다. 정답 어종의 이웃이 하나도 없으면 정답 확률이 0이 된다. −log(0)은 끝없이 커지므로 계산할 때는 아주 작은 값으로 잘라 쓰는데, 그래도 큰 벌점이 남는다. **자신 있게 틀린 것**에 가장 큰 벌점이 붙은 것이다.
- 코드:

```python
from sklearn.metrics import accuracy_score, log_loss
accuracy_score(y_test, model.predict(X_test_s))
log_loss(y_test, model.predict_proba(X_test_s), labels=model.classes_)
```

## 슬라이드 17 — 경사하강법 = 영점 사격

- 라벨: `SECTION 4 · 경사하강법`
- 제목: **쏘고, 탄착을 보고, 반대 방향으로 조정한다**
- 본문:
  - 손실 함수를 산의 지형이라 하면, 가장 낮은 골짜기가 목표다. 안개가 껴서 전체는 안 보이고 발밑의 경사만 느낄 수 있다.
  - 영점 사격으로 보면: 탄착군이 오른쪽 위로 쏠렸으면(기울기) 가늠자를 왼쪽 아래로 돌린다. 몇 클릭 돌릴지가 학습률이다.
- 규칙 상자 (크게):

```
새 가중치 = 현재 가중치 − 학습률 × 기울기
```

- 역할 구분 띠: **손실 함수 = 지형(0층위에서 정함)** / **기울기 = 발밑 경사** / **학습률 = 보폭(②층위에서 정함)**
- 하단: 학습률을 잘못 주면 최적점에 **도달하지 못할** 뿐, 최적점 자체가 바뀌지는 않는다.
- [그림] 안개 낀 산비탈을 내려가는 등산가 + 옆에 작은 표적지 아이콘

## 슬라이드 19 — SGD 한 번의 학습 단계

- 라벨: `SECTION 4 · SGD`
- 제목: **확률적 경사하강법 — 매 에포크의 6단계**
- 기준: 훈련 118마리, 배치 16, 7어종, 4개 입력
- 단계 그림 (원 6개 가로 배치):
  1. **섞기** — 118마리 순서를 무작위로 섞는다
  2. **묶기** — 16마리씩 자른다 (7묶음 × 16 + 마지막 6마리 = 8묶음)
  3. **예측** — 각 물고기의 7어종 확률을 계산한다
  4. **채점** — 크로스 엔트로피로 손실을 잰다
  5. **기울기** — 손실을 줄이려면 가중치를 어느 쪽으로 움직일지 계산한다
  6. **조정** — 가중치를 학습률 × 기울기만큼 옮긴다
- 아래 두 상자:
  - **확률적(Stochastic)**: 전체가 아니라 무작위로 뽑은 일부(배치)로 기울기를 계산한다. 방향은 조금 흔들리지만 계산이 빠르다.
  - **가중치 개수**: 입력 4개 × 어종 7개 + 절편 7개 = 35개의 숫자를 동시에 고친다.
- 코드:

```python
for epoch in range(n_epochs):
    perm = rng.permutation(n)                      # ① 섞기
    for s in range(0, n, batch_size):              # ② 묶기
        j = perm[s:s+batch_size]
        P = softmax(X[j] @ W + b)                  # ③ 예측
        g = (P - Y[j]) / len(j)                    # ④⑤ 채점·기울기
        W -= lr * X[j].T @ g;  b -= lr * g.sum(0)  # ⑥ 조정
```

## 슬라이드 20 — 학습률: 한 번에 몇 클릭?

- 라벨: `SECTION 5 · 학습률`
- 제목: **보폭이 작으면 느리고, 크면 골짜기를 건너뛴다**
- 본문: 학습률은 사람이 정하는 값, 즉 **하이퍼파라미터(②층위)** 다. 배치 크기, 에포크 수도 마찬가지다.
- 표:

| 학습률 | 비유 | 예상되는 모습 |
|---|---|---|
| 0.001 ~ 0.01 | 개미 걸음 / 한 번에 1클릭 | 손실이 아주 천천히 줄어든다 |
| 0.1 ~ 1 | 보통 걸음 | 매끄럽게 줄어든다 |
| 10 ~ 50 | 거인 걸음 / 한 번에 수십 클릭 | 손실이 튀어 오르며 들쭉날쭉 |

- 경제학 대응: 학습률 = 부분조정모형의 **조정 속도**. 너무 크면 균형점을 지나쳐 진동한다.

- 2단 상자:

  - **너무 많으면** 이 사격장의 바람과 조명에 지나치게 맞춰져 다른 사격장에서 빗나간다 → 과적합
- 하단: 그래서 검증 성적이 더 좋아지지 않으면 멈추는 **조기 종료(Early Stopping)** 를 쓴다.
- 참고 띠: LogisticRegression은 내부에서 알아서 반복하고, KNN은 반복 학습 자체가 없어서 에포크를 지정하지 않는다.

## 슬라이드 27 — Phase #2: 하이퍼파라미터 다시 보기 (KNN의 k)

  2. **어려움은 특정 어종에 몰려 있다** — 오답 대부분이 Roach↔Perch, 그리고 6마리뿐인 Whitefish다. 평균 정확도만 보지 말고 어디서 틀리는지 본다.
  3. **앙상블은 만능이 아니다** — 같은 곳에서 틀리는 모델끼리는 보팅해도 그대로이고, 너무 약한 그루터기는 부스팅해도 7어종을 못 가른다.
  4. **튜닝과 변수가 절반 이상이다** — 로지스틱 회귀의 C 하나로 평균 81.4% → 93.2%, 비율 변수 하나로 KNN 79.2% → 83.5%, 2차항으로 회귀 오차 143g → 49g.
