시리즈 비유 — 영점 잡기

손실은 탄착점과 정중앙의 거리, 기울기는 탄착군이 쏠린 방향, 학습률은 한 번에 돌리는 클릭 수, 배치는 몇 발 쏘고 조정할지, 에포크는 지급된 탄을 몇 바퀴 쏠지입니다. 경사하강법·학습률·배치·에포크는 한 사수가 영점을 잡는 법이고, 앙상블은 여러 사수의 결과를 합치는 법입니다. 그림에는 총을 넣지 않고 표적지와 다이얼만 씁니다.

앞 실습(KNN·SVC)과 연결

Phase #1
데이터와 알고리즘을 정하고 기본값으로 학습 → 1장, 2장에서 상자를 연다
Phase #2
k, kernel, C 고르기 → 1장(무엇으로 고르나), 4장(본격 탐색)
Phase #3
변수 바꾸기·늘리기 → 1장 ②칸(회귀), 4장 ③칸(분류)

사용법

  • 각 장은 파일 하나로 열립니다. 인터넷은 글꼴에만 씁니다.
  • 그래프 옆 실제 데이터 표시는 페이지가 직접 계산한 값, 설명용 그림·scikit-learn 값 표시는 각각 그림과 실험 스크립트 값입니다.
  • 각 장 끝의 지식 색인과 온톨로지·서지 꾸러미에서 개념 그래프와 참고문헌을 내려받을 수 있습니다.
  • 실험 스크립트(scikit-learn)와 데이터는 저장소의 experiments/에 있습니다.
