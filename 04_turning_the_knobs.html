1고무줄

규제 손잡이 C — 계수에 고무줄 달기

② 하이퍼파라미터연구실: 측정값을 고무줄로 붙잡기로지스틱 회귀

연구실에서는

계수마다 0으로 당기는 고무줄을 달았다고 해 봅시다. 고무줄이 세면 계수가 커지지 못하고, 느슨하면 데이터에 맞춰 마음껏 커집니다.

모델에서는

scikit-learn LogisticRegression의 C는 고무줄의 느슨함입니다. 목적식 = C × Σ손실 + ½‖계수‖². C가 작으면 규제가 세고(계수가 작게), 크면 규제가 약합니다. 기본값은 C = 1입니다.

C를 바꿔 보기 실제 데이터 · 교차검증과 시험 모두 페이지 계산

행동으로 보기 — 고무줄에 묶인 계수 35개

C5겹 교차검증시험 (봉인)계수 크기 ‖W‖

초보자 풀이

  1. C = 0.01: 고무줄이 너무 세서 계수가 거의 0입니다. 어종을 가르지 못합니다(과소적합).
  2. C = 1(기본값): 1~3장의 82.5%가 이 설정이었습니다. 7어종을 가르기엔 고무줄이 아직 셉니다.
  3. 교차검증은 C = 100을 고릅니다. 고른 뒤 봉인을 열면 시험 97.5%입니다.
  4. C = 1000은 시험에서 100%지만 교차검증은 C = 100보다 낮습니다. 시험 점수로 C = 1000을 고르면 1장의 누수입니다.

이 칸의 한계: 손잡이 하나로 82.5% → 97.5%. 그런데 이것은 로지스틱 회귀의 손잡이입니다. 다른 모형(SVC)의 손잡이는?

수식으로 보기

목적식 J(W) = C · Σᵢ [−log p_(yᵢ)(xᵢ)] + ½ Σ w². 절편은 규제하지 않습니다. 이 페이지는 이 목적식을 감쇠 뉴턴법으로 풀어 scikit-learn과 같은 값(C=1 → 82.5%, C=100 → 97.5%)을 냅니다. C가 커질수록 규제항의 몫이 작아져 계수가 커집니다.

데이터 분석으로 치면

회귀분석의 릿지·라쏘가 같은 원리입니다. 변수가 많고 표본이 적을 때 계수를 0 쪽으로 당겨 새 데이터에서 덜 흔들리게 합니다.

한계: 이 데이터는 관계가 뚜렷해 규제를 풀어도 손해가 적었습니다. 잡음이 많은 데이터에서는 반대일 수 있습니다.

주판봇

기본값 C=1에서 82.5%였는데 손잡이 하나 돌렸더니 97.5%? 모델을 바꾼 것보다 크잖아.

SVC의 kernel과 C — 그리고 100%의 함정

② 하이퍼파라미터연구실: 남의 실험 노트 옮겨 적기SVC (scikit-learn 값)

연구실에서는

다른 연구실의 실험 노트를 옮겨 적을 때는 "우리 장비로 다시 재지 않았다"고 표시합니다.

모델에서는

SVC는 이 페이지에서 계산하지 않고 실험 스크립트(scikit-learn)의 결과를 옮겼습니다. kernel(경계의 모양: 직선·곡선·다항식)과 C(경계를 얼마나 날카롭게 그을지)를 바꿔 교차검증으로 골랐습니다.

kernel × C 교차검증 지도 scikit-learn 실험 스크립트 값

행동으로 보기 — 시험 100%가 나온 분할과 나머지 19번

초보자 풀이

  1. 교차검증 최고는 linear, C = 100(89.8%)입니다. 시드 42의 시험 40마리에서는 한 마리도 틀리지 않았습니다(100%).
  2. 하지만 분할을 20번 바꾸면 평균 94.2%, 최저 90.0%입니다. 100%는 운 좋은 분할에서 나온 값입니다.
  3. 그래도 20번 모두 90% 이상이라 기본 설정(약 80%)보다 확실히 낫습니다.

초보자 풀이

  3. 변수가 바뀌자 고른 k도 3 → 5로 바뀌었습니다. Phase #3을 하면 Phase #2를 다시 해야 합니다.

현장에 옮기면

도메인 지식으로 만든 변수(비율, 차이, 단위당 값)는 모델을 바꾸는 것보다 싸고 효과가 클 때가 많습니다. 공정 데이터라면 온도 대신 온도 변화율, 생산량 대신 단위 시간당 생산량을 넣어 보는 식입니다.

한계: 변수를 많이 만들어 시험 점수로 고르면 누수가 됩니다. 변수 선택도 교차검증 안에서 합니다.

  1. 기본 설정 모형(로지스틱 C=1, KNN k=5)끼리의 차이는 1~2%p로, 표준편차(약 3%p)보다 작습니다. 이 차이로는 우열을 말할 수 없습니다.
